# Archive

This directory contains historical or one-off material that is not part of the
maintained application workflow.

- `powerapps/` contains unpacked legacy Power Apps exports and source snapshots.
- `dev-artifacts/` contains old export packages, API probes, and one-time source
  migration scripts. Several scripts retain their original machine-specific
  paths and are preserved for reference only.

New development should target the projects under `apps/`.
